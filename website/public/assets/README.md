# 素材槽位 · Asset Slots

把图片按下面的文件名丢进对应目录,**刷新页面即可生效,不需要改代码**。
任何一张图缺失时,双世界版会自动回退到程序化生成的「全息档案卡」占位图,
所以你可以一次只补一部分。

```
public/assets/
├── characters/
│   ├── knight.png          角色立绘   900×1350  透明 PNG
│   ├── knight-face.png     角色头像   480×480   方图(可选)
│   ├── mage.png
│   ├── rogue.png

│   ├── dungeon.jpg

│   ├── string.jpg          首屏·弦界侧背景 1920×1080

└── logo.png                站点 LOGO,高度 ≥ 120px 透明 PNG
```

## 出图建议

**角色立绘**:透明背景、竖构图、人物居中偏下,顶部留一点空间给发光描边。
卡片会做「弦化」压扁动效,所以左右两侧各留 5% 安全边距,避免翻转时被裁到。

**章节主视觉**:横构图,主体避开左下角(那里会压章节标题)。
偏暗的图在异环侧更好看,偏亮的图在弦界侧更好看。

**首屏背景**:会被对角分屏裁切,重要内容放在画面中央偏外侧
(`string.jpg` 的主体靠左,`nte.jpg` 的主体靠右)。
