# Treasure Chest（普通宝箱）重画与设计提案

## 本次对象

- 类别：场景 / 地牢交互物 / 掉落容器
- 对象类型：`ChestKind = "treasure"`
- 几何入口：`src/game/dungeon/ChestGeometry.ts`
- 绘制入口：`src/game/render/ChestRenderer.ts`
- 自动验证：`scripts/chest-geometry-smoke.ts`
- 近期未处理：最近的提案集中在 Garden Wish Fountain、角色、熔岩/森林/雪地怪物与 Hub 设施；未发现普通 Treasure Chest 的独立重画记录。

## 当前实现观察

当前普通宝箱由 `ChestRenderer` 使用矩形像素块分层绘制，支持 forest、dungeon、snow、lava 四套主题色。闭合状态由 30 px 左右的盖体、32 px 宽箱身、中轴金属带、中央锁孔与两侧包角组成；开启后盖体上移并后翻，箱体内部出现暗腔和一条主题强调色。开启态额外绘制四个固定闪点。

几何层已明确分离箱盖、箱身、阴影、掉落锚点和物理占地。自动测试要求盖体开启后清除前方掉落区域，宝物生成点位于箱体前方，开闭状态均保持碰撞稳定。因此本次只调整视觉分层、材质、状态和动画，不改变现有锚点、占地和掉落规则。

## 现状问题

1. **轮廓过于标准化**：闭合时整体接近规则长方箱，四个章节主要依赖换色，远距离无法从结构判断当前区域。
2. **盖体与箱身连接感不足**：开启动作直接切换两个静态锚点，缺少铰链受力、锁扣解除和重量转移。
3. **可开启状态表达偏弱**：未开启宝箱没有低频提示，中央 2×2 accent 像素容易被环境高光吞没。
4. **开启瞬间层次不足**：开箱后立刻出现暗腔和闪点，缺少“解锁—抬盖—内光释放—掉落落地”的清晰顺序。
5. **章节材质只有配色差异**：森林木箱、地牢石箱、雪地冷封箱与熔岩耐热箱的结构语义尚未建立。
6. **闪点位置固定且节奏机械**：四个闪点围绕掉落锚点循环，但没有与箱盖开启、掉落数量或稀有度形成对应。
7. **Boss Chest 与普通箱的层级接近**：Boss Chest 更宽、更紫、更亮，但普通箱若持续发光，仍可能削弱两者奖励层级差。

## 视觉目标

- 保留“低矮、正面开启、前方掉落”的核心读法，并严格服从现有几何与碰撞。
- 普通宝箱第一眼读为可拾取奖励容器，第二眼读出章节材质；Boss Chest 继续拥有明显更宽、更高、更仪式化的层级。
- 在 320×240、1× 缩放下，锁扣、盖缘、箱脚和开启暗腔至少形成四个稳定块面。
- 将开箱过程拆成可读时间线，避免单帧跳变。
- 所有章节共享同一基础构造，只通过盖形、包角、表面纹理和少量附加件区分，避免维护四套完全独立资产。

## 轮廓与配色

### 基础轮廓

采用“低拱盖 + 外露铰链 + 收腰箱身 + 四角短脚”的结构：

1. **低拱盖**：保留现有 30 px 宽度，但顶部中央抬高 2 px，两侧压低，形成轻微弧顶，不再是纯矩形盖板。
2. **外露铰链**：箱体左右后侧各显示 2×3 px 深色铰链块，开启时保持与盖体相连，强化机械因果。
3. **收腰箱身**：箱体上缘 32 px，腰部内收至 28 px，底部短脚恢复到 30 px，形成更清楚的容器体积。
4. **中央锁扣**：中轴金属带在锁扣位置加宽，锁孔改为倒梯形或短菱形，避免像普通装饰点。
5. **四角短脚**：底部左右脚保持在现有碰撞边界内，用深色脚块明确落地面和阴影。

### 章节材质差异

- **Forest**：木板横纹、藤扣包角、绿色蜡封。主体仍是棕木，不增加叶片粒子。
- **Dungeon**：冷灰石板或铁木复合，紫色符文封条，包角更方正。
- **Snow**：蓝灰箱体、银白包边、盖缘有短冰封齿；高光面积严格受控，避免融入雪地。
- **Lava**：深灰耐热壳、铜红包角、橙色隔热缝；不开启时不持续喷火。

### 建议层级

- 轮廓暗边：最深值，连续包围主体。
- 主体中间色：约 55% 面积。
- 材质高光：约 15% 面积，集中在左上盖缘和箱身上沿。
- 金属带：约 18% 面积。
- 可交互 accent：不超过 6%。
- 开启核心白：仅在开箱关键帧出现，持续时间极短。

## 动画与特效需求

### 关闭待机

- 锁扣每 1.8–2.4 秒出现一次单像素亮度呼吸，不改变整体尺寸。
- 仅在玩家进入可交互距离后，盖缝出现 1 px 的主题色间歇亮线。
- 不绘制常驻漂浮粒子，保持普通奖励层级低于 Boss Chest。

### 解锁前摇

建议总时长 0.16–0.20 秒：

1. 0.00–0.06 秒：锁扣向下移动 1 px，中央 accent 熄灭。
2. 0.06–0.12 秒：中轴金属带产生短促白色切点，表示锁舌释放。
3. 0.12–0.20 秒：盖体前缘抬起 1–2 px，箱身保持不动。

### 抬盖

建议 0.18–0.24 秒：

- 盖体沿当前 closed/opened anchors 之间插值，而非直接切换。
- 前半段移动较慢，后半段加速后轻微回弹 1 px。
- 左右铰链随盖体旋转感分两帧改变形状：先压缩，再拉长。
- 箱身不后退、不缩放，避免掉落锚点和碰撞认知漂移。

### 内光释放

- 盖体越过箱身上缘后，暗腔先出现，再在 1–2 帧后绘制主题 accent。
- 中央核心高光最大宽度不超过 8 px，不使用覆盖箱体的大面积光柱。
- 内光向前方掉落锚点延伸 4–6 px，明确奖励将落在箱前，而非箱内。

### 掉落与余光

- 掉落生成时，根据掉落数量绘制 1、2 或 3 个短光点，位置与 `getChestLootSlotOffsets()` 对齐。
- 闪点持续 0.20–0.35 秒后衰减；普通箱最多同时 4 个亮点。
- 打开后的箱体仅保留暗腔和低亮边缘，不继续周期性闪烁。

## 场景与玩法可读性要求

- 开启盖体必须继续满足自动测试：盖体下缘不得侵入箱身前部和掉落区域。
- 视觉脚部、阴影和物理 footprint 必须一致，不能出现“看似可穿过但实际阻挡”的侧边。
- 掉落光点必须落在现有 loot anchor 及 slot offsets 附近，不得暗示奖励从箱后生成。
- 主题材质差异不能改变宝箱可开启身份；四种主题仍需共享中央锁扣和前向开口。
- 普通箱的最高亮度必须低于 Boss Chest 核心亮度，且持续时间更短。
- 开箱特效不得覆盖敌方弹体、地面危险区或房间出口提示。
- 去色后，普通箱应通过低拱盖、收腰箱身和中央锁扣与地面装饰、祭坛、棺材类敌人区分。

## 具体概念方案：Chapter-Locked Field Chest

将当前普通宝箱重组为五个可独立调整的视觉层：

1. `shadow`：维持现有双层矩形阴影，但根据脚部轮廓收窄中心段。
2. `body shell`：收腰主体、四角短脚、章节材质纹理。
3. `front hardware`：中轴带、锁扣、左右包角，承担可开启身份。
4. `hinged lid`：低拱盖与外露铰链，沿锚点插值执行开启动画。
5. `reward light`：暗腔、短前向光带和与掉落槽位一致的闪点。

四个章节仅替换盖缘、材质纹和包角造型，不改变关键识别点与几何尺寸。Boss Chest 继续使用更宽箱体、侧柱和中央仪式核心，不复用普通箱的低拱盖比例。

## 实现建议

### `src/game/render/ChestRenderer.ts`

- 将 `opened: boolean` 扩展为渲染层可消费的连续 `openProgress?: number`；玩法状态仍可保持布尔值，由 DungeonState 维护短时动画计时。
- 将普通箱绘制拆分为：`drawTreasureShell`、`drawTreasureHardware`、`drawTreasureLid`、`drawTreasureInterior`。
- `drawTreasureLid` 在 closed/opened anchors 之间做确定性插值；不要在 Renderer 中创建独立随机计时器。
- `drawSparkle` 接收掉落数量或槽位列表，使光点与实际掉落位置一致。
- 章节差异使用结构化 `ChestVariantDetails`，除颜色外支持 `lidProfile`、`cornerShape`、`surfaceMarks`。
- 打开后停止待机呼吸，防止空箱继续吸引注意力。

### `src/game/states/DungeonState.ts`

- 在宝箱开启事件中记录 `openedAt` 或短时 `openAnimationTime`。
- 掉落生成时点建议位于盖体进度 65%–75%，确保视觉上已腾出前方空间。
- 保留现有 `resolveChestLootPositions()` 和 `baseY` 持久化逻辑。

### 自动验证

扩展 `scripts/chest-geometry-smoke.ts`：

- 检查 `openProgress = 0 / 0.5 / 1` 三个阶段的盖体边界。
- 检查四个主题均包含连续深色外轮廓和中央锁扣色块。
- 检查打开后普通箱不再绘制周期性锁扣呼吸。
- 检查 1–3 个掉落的闪点与 slot offsets 误差不超过 2 px。

## 验收标准

- [ ] 320×240、1× 缩放下，可明确读出低拱盖、收腰箱身、中央锁扣和四角短脚。
- [ ] forest、dungeon、snow、lava 四主题不只依赖换色，至少各有一项盖缘或包角差异。
- [ ] 普通箱与 Boss Chest 在去色后仍有明显宽高比和结构层级差。
- [ ] 开箱动作包含解锁、抬盖、内光和掉落四个阶段，总时长控制在 0.35–0.55 秒。
- [ ] 盖体在所有中间帧均不遮挡箱前掉落区域。
- [ ] 掉落闪点与实际 1–3 个掉落槽位对齐，误差不超过 2 px。
- [ ] 打开后的空箱不继续高亮呼吸或生成周期性闪点。
- [ ] 所有动画由时间和状态确定，不引入每帧随机数。
- [ ] 物理 footprint、掉落锚点和现有碰撞行为保持不变。
- [ ] 开箱最高亮度和粒子数量始终低于 Boss Chest。

## 后续评审重点

1. 低拱盖抬高 2 px 后，是否仍能在开启状态清楚避让箱身。
2. 收腰幅度是否会削弱箱体容量感。
3. 四章节结构差异是否足够，但不会增加过多绘制分支。
4. 内光前向延伸是否准确指向实际 loot anchor。
5. 普通箱开箱时长是否需要按房间安全状态缩短。
6. Snow 主题高光是否在雪地背景中丢失暗边。
7. Lava 主题隔热缝是否会被误读为持续燃烧陷阱。
