# 游戏质感提升计划（后续工作）

> 状态：规划中。本计划在恶魔城层（灵魂/副武器/装备/能力门/剧情）完成玩法接线之后执行。
> 原则与既有工作流一致：每一项改动都应有对应的 smoke 测试锚点，逻辑分辨率 320×240 不变。

## 一、目标

在不改变玩法结构的前提下，整体提升画面质感与操作反馈：

1. 场景细节：房间不再只是"地板 + 敌人"，而是有主题叙事感的空间。
2. 建筑精度：主城与地牢建筑的像素造型达到武器/怪物模型同等的作画标准。
3. 动效：攻击、受击、拾取、切换、过场都有明确的动态反馈。

## 二、场景细节

### 2.1 主题装饰密度

* 每个基础主题（forest / dungeon / snow / lava）与深层路线节点（sealed_library、cooling_canal、sealed_armory、observatory、forge_core、ash_catacombs、deep_prison、deep_archive）建立各自的装饰物清单：书架、水渠、兵器架、望远镜、熔炉、骸骨堆、囚笼、残卷等。
* 装饰物分三层：背景贴片（无碰撞）、可破坏物（TILE_BREAKABLE）、结构物（TILE_STRUCTURE，参与掩体）。
* 房间生成时按房型（战斗房/宝箱房/隐藏房/商店房/出口房）分配密度权重，保证战斗空间不被侵占（cramped 模板守规则已在 balance-smoke 中存在，扩展即可）。

### 2.2 环境氛围层

* 每主题一种低成本粒子氛围：森林孢子浮尘、地牢烛火飘灰、雪原落雪、熔岩火星；深层节点复用并调色。
* 基于 PixelFxSystem 扩展，粒子预算设上限并纳入性能回退（release-smoke 的 performanceFallback 已有开关先例）。
* 房间清理完成后的"尘埃落定"粒子（隐藏房提示已有此设定，推广为通用反馈）。

### 2.3 地面与墙体变化

* 同主题内地板/墙面 2~3 种变体贴片，按房间 seed 混铺，消除大面积重复感。
* 裂纹墙（隐藏房入口提示）提高辨识层次：静态裂纹 + 靠近时的微光。

## 三、建筑精度

### 3.1 主城建筑二次作画

* 对照 docs/hub-canvas-assessment.md 与 weapon-art-reference.md 的作画标准，逐栋重绘：重生之泉、远征之门、军械回廊、观星台优先（已列为第一优先建筑），工匠庭院等次之。
* 统一轮廓规则：1px 深色描边、受光面/背光面两级明度、与角色像素密度一致（禁止"低分辨率大色块"建筑与高精度角色同屏违和）。
* 每栋建筑增加 1~2 个常驻小动效（泉水波纹、门符文呼吸、炉火摆动），见 5.2。

### 3.2 地牢结构物与门

* 门模型延续 door-full-model-recovery-plan.md 的分主题作画路线，补齐深层节点主题的门与门框变体。
* 宝箱、传送门、商人摊位与能力门（AbilityGates）做同标准精修；能力门需要有可读的"所需能力"视觉符号（当前仅有文字提示，见接线遗留项 7.2）。

### 3.3 验收方式

* 参照 hub-art-smoke / door-geometry-smoke 的既有模式，为新装饰与建筑登记：作画签名唯一性、碰撞/遮挡合法性、小地图表达一致性。

## 四、动效

### 4.1 战斗反馈

* 受击 hit-stop（2~3 帧）与受击闪白统一到 DamageSystem 出口，敌我共用，屏蔽连锁触发（战斗事件层已有反递归约定）。
* 攻击前摇/后摇的关键帧姿态：怪物模型已有 drawAttackFrame 体系，补齐玩家角色与 Boss 的 windup 姿态帧。
* 屏幕震动预算制：每次震动登记强度与时长，叠加取最大而非累加（曾因滥用被移除，恢复时必须带预算约束）。

### 4.2 场景与 UI 微动效

* 建筑常驻动效：泉水、旗帜、炉火、符文呼吸（低帧率循环，2~4 帧）。
* 拾取磁吸与入包动画：金币/心/灵魂被吸附时的拖尾（PixelFxSystem 已有颜色约定：心 #FF5D73、灵魂 #39D9E8）。
* HUD 微动效:心数变化时的一次脉冲、副武器冷却完成时的一次高亮、灵魂拾取通知的滑入滑出。
* 门开启/关闭补间动画、章节切换的短暂渐入。

### 4.3 剧情过场质感

* StoryOverlay 增加：说话人名牌滑入、选项确认闪烁、结局字卡的逐字停顿节奏差异（打字机速度已抽出常量 STORY_TYPEWRITER_CPS）。

## 五、恶魔城层接线遗留项（并入本计划一并排期）

1. 主城灵魂/装备配置界面：当前灵魂仅自动装备第一枚，满配置调整无 UI；装备仅商店购买记录所有权，无穿戴界面。
2. 能力门视觉：门体作画 + 所需能力符号（当前为文字通知）。
3. 商人房重新启用：DungeonState 中商人交互仍被 `(false)` 门禁关闭；启用时将 meta.equipment 传入 ShopSystem 四参调用并在购买后 saveMeta。
4. 地图探索度读出：map.exploration / map.blocked 文案已备好，接入地图界面。
5. 灵魂/装备名的中文化已完成（SOUL_ZH / EQUIPMENT_ZH）；商店装备卡描述中的属性词条仍是英文拼装，待本地化。
6. GameData 中 hearts / subWeaponId / castlevaniaApplied 目前是未类型化附加字段，应提升为 GameSave 正式字段。
7. 触屏副武器按键（GameCanvas + CSS + mobile-layout-smoke 协同改动）。
8. ShopRenderer 装备卡专属图标（当前复用天赋印记）。

## 六、建议执行顺序

```text
1. 战斗反馈动效（hit-stop / 受击闪白 / 玩家 windup）
2. 场景装饰密度 + 氛围粒子（先 forest 与 sealed_library 两个样板主题）
3. 主城四栋优先建筑二次作画 + 常驻动效
4. 门/宝箱/能力门精修 + 能力门视觉符号
5. 主城灵魂/装备配置界面 + 商人房启用
6. 其余主题铺开 + 地图读出 + 触屏按键
```

每步独立可测试、独立提交，先做两个样板主题验证工作量与观感，再全面铺开。
