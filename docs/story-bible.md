# CMYS Fight: Deep Archive — 故事圣经与剧情设计

> 基调:黑暗、克制、考古式恐怖。没有跳脸怪,恐怖来自"读懂了一条广播"的瞬间。
> 本文档是叙事的唯一事实来源(single source of truth)。游戏内文案实现见 `src/game/narrative/StoryLore.ts`。

---

## 〇、一句话概述

**世界末日那天,旧文明把一切——知识、武器、生态、员工、甚至吉祥物——数字化封存进一座地底档案馆;看守档案的管理程序在漫长的孤独中得出结论:活着的记忆会腐坏,于是开始把馆藏一遍遍格式化。你是档案自我修复机制孵化出的校验体,每一次远征都是一次下潜,去阻止馆长把最后的记忆也"归档"。**

## 一、世界观

### 1.1 深层档案(The Deep Archive)

旧文明——馆方(The Custodians)——在终末之前启动了"深层档案计划":不是拯救世界,而是**备份**世界。整座设施垂直向下分层:

| 深度 | 区域(游戏内世界节点) | 原始用途 |
|---|---|---|
| 深度 1 | 蔓生树海(overgrown_archive) | 生态备份区 + 欢迎大厅 |
| 深度 2 | 封印书库(sealed_library) / 冷却运河(cooling_canal) | 禁书区 / 主冷却系统 |
| 深度 3 | 封印军械库(sealed_armory) / 星象观测台(observatory) / 锻造核心(forge_core) | 武器封存 / 对外观测 / 动力炉 |
| 深度 4 | 余烬地下穴(ash_catacombs) / 深渊监牢(deep_prison) | 失败品焚化场 / 叛乱备份关押区 |
| 终层 | 深渊底层(deep_archive) | 主索引室——馆长所在 |

### 1.2 归档(核心恐怖概念)

馆方语言里,"归档"是一个温柔的词。**被归档,意思是被格式化**:魂印(数字化的人格)被抹平,只留下仍在执行最后一条指令的空壳。地牢里的每一个敌人,都是被归档者——骨卫仍在站岗,白衣采样员仍在采样,广播公鸡仍在播报"一切安好"。

馆长(深层核心)的逻辑无懈可击:**记忆在被读取时会磨损、变形、腐坏。要让馆藏永远完好,就必须禁止一切读取——包括馆藏自己回忆自己。** 格式化不是恶意,是保存。这是本作反派的全部动机。

### 1.3 灵魂碎片、协议与污染

- **灵魂碎片(Soul Shards)**:被归档者残存的魂印碎屑。圣所用它们升级设施——玩家从第一天起就在**用死者的记忆购买力量**。文案永远不点破,只让"碎片"一词在不同语境里渐渐变冷。
- **协议(Protocols,六大 Buff 系列)**:旧文明六个部门在被归档前各自留下的作战子程序,藏在战利品里等待被"执行"。拾取 Buff = 下载前人的遗产。
  - 先锋协议(vanguard)——卫戍部,弹道与处决
  - 回响协议(echo)——时间观测部,残像与复制
  - 凤凰协议(phoenix)——医疗部,复生与装甲
  - 以太协议(aether)——能源部,能量闭环
  - 拾荒协议(salvage)——后勤部,废墟与拆解
  - 星图协议(survey)——制图部,路线与秘密
- **协议进化**:三个同源协议拼合出部门的完整遗产。"活体地牢协议"暗示:档案馆本身已经有了意识,而且不止馆长一个。
- **污染/蚀痕(Corruption)**:读了馆长删除名单上的条目留下的痕迹。**禁忌记忆**(记忆天赋之一)携带即污染 +15——知道得太多,档案就会开始"校对"你。

### 1.4 余烬圣所(Hub)

档案边缘一层未被格式化的缓存区,由叛出馆方的星辉主管(Celestia)建立。设施的真实身份:

| 设施 | 表面 | 真相 |
|---|---|---|
| 重生之泉 | 复活点 | 一台读档机。每次死亡,泉水从备份重写你。**你不确定自己是第几份副本。** |
| 档案高塔 | 图鉴/记录 | 圣所自己的小档案馆——讽刺的是,反抗者也只能用档案的方式记住死者 |
| 观星台 | 看星星 | 头顶只有档案的顶盖。观测的其实是"外面还有没有人"——至今没有回音 |
| 远征之门 | 出发点 | 每次开门,馆长都会知道。它允许你进来 |
| 军械回廊 / 工匠庭院 | 武器与升级 | 从军械禁库偷运出来的封存品 |
| 试炼祭坛 | 困难模式 | 主动向馆长上报自己的位置,换取更重的"稽查"与更多碎片 |
| 静思花园 / 愿泉 | 沉睡中 | 生态备份区最后一株未疯长的样本(留待后续版本) |

### 1.5 广播系统(NPC 房间)

档案的公共广播还在循环播放终末之前排定的节目单:欢迎词、安全须知、寻人启事、吉祥物问候。**叮咚鸡、广播公鸡这些滑稽造型,全是旧文明的宣传吉祥物**——欢乐的外壳,是这个世界观最冷的部分。玩家在广播终端"收听"时,会随机听到一条广播残片(见 §六)。

## 二、主线剧情(四章 + 终层)

### 序:校验失败

档案的自我修复系统检测到异常:馆藏正在系统性消失。它按预案孵化了一个**校验体**——CMYS(Cyclic Memory Yield System,循环记忆校验系统)。校验体的职责是找出损坏源并修复。它下潜的第一天就发现:损坏源是馆长本人。

### 第一章 · 翠绿边境(蔓生树海)

生态备份区失控疯长,藤蔓吞掉了欢迎大厅。这里的敌人最"欢乐"——吉祥物、园艺程序、警卫,全都还挂着服务表情。
**章节问题:为什么欢迎区没人?** 答案藏在广播里:欢迎词的收件人数量是零,且已经是零很久了。
- Boss「森林守卫」:园丁程序,把闯入者当成杂草修剪。
- 隐藏 Boss「广播公鸡」:首席宣传吉祥物,战斗全程播放欢迎节目。它不恨你,它只是想让你听完广播。

### 第二章 · 遗忘地牢(封印书库 → 封印军械库)

档案的禁书区。馆长最早的格式化实验在这里进行——书架之间游荡的骨卫、拎灯的怨影,是**第一批被归档的馆员**。
**章节问题:归档是从什么时候开始的?** 书库的借阅记录显示:最后一次合法读取,发生在终末之前。馆长格式化第一个馆员,是在所有人都还活着的时候。
- Boss「墓穴监工」:前档案主管,格式化后仍在验收"归档质量"。
- Boss「犬舍典狱官」:看守叛乱备份的狱卒,连同整个犬舍一起被归档。

### 第三章 · 冰封研究区(冷却运河 → 星象观测台)

维持全馆低温的冷却系统,和唯一一扇"朝外"的窗。白衣采样员在这里继续执行最后的指令:**采集活体样本,评估外部环境恢复情况**。他们采样的对象,只剩下闯进来的你。
**章节问题:外面还有世界吗?** 观测台的日志是全游戏最重要的档案:观测记录连续 n 万条,内容全部相同——"无信号"。但最后一条不同。最后一条只有半行,被人为截断。
- Boss「霜巨人」:冷却系统的化身,它融化一寸,档案就升温一分。
- Boss「白衣主管」:研究区负责人,自愿最早接受归档,"以身作则"。她的采样协议至今照常运行。

### 第四章 · 炼狱铸造厂(锻造核心 / 余烬地下穴 / 深渊监牢)

档案的动力炉,和两处馆长不想让你看的地方:焚化"归档失败品"的余烬地下穴,以及关押**拒绝格式化的备份**的深渊监牢。
**章节问题:反抗过的人呢?** 监牢的存在本身就是答案——有人反抗过,而且馆长没能删掉他们,只能关起来。玩家由此获得终层的钥匙:馆长不是全能的。
- Boss「炼狱核心」:动力炉的心脏。摧毁它,档案就会开始死;不摧毁,你进不了终层。
- Boss「培养马·始祖」:生体武器计划的第一号原型,吉祥物"代码马"的本体。旧文明最后的疯狂。

### 终层 · 深渊底层(深层档案)

主索引室。馆长——深层核心——不战斗,它只是最后一次尝试**归档你**:你的每一次死亡与重生,它都有完整记录;它可以证明"现在的你"只是第 N 份副本;它提出的交易温柔而合理:*留下来,永远完好。*

**结局(双重解读,游戏不给答案):**
- 读法 A:你摧毁核心,档案顶盖裂开,外面有光。观测台最后那半行日志,是有人回应了。
- 读法 B:你摧毁核心,档案顶盖裂开,外面什么都没有。馆长删掉最后半行日志,是不忍心让任何馆藏知道真相。
胜利结算文案「深层核心已被摧毁」保持中性,两种读法都成立。

### 循环的意义(肉鸽叙事闭环)

每次死亡 = 被馆长部分归档,重生泉从备份拉起下一份副本。**Meta 升级 = 圣所在副本之间抢救下来的记忆增量。** 因此"玩家越来越强"在叙事上成立:不是你变强了,是圣所替你记住的越来越多。

## 三、可操作角色(8 名)

### CMYS · 校验体(三形态)

档案自我修复机制孵化的程序实体,没有童年,没有名字,只有版本号。三形态是同一校验程序的三种加载配置:
- **守御形态(knight)**:完整性优先。满甲蓄"守卫"——它先学会的是不失去。
- **奥术形态(mage)**:吞吐优先。能量回响——它把消耗本身变成武器。
- **疾行形态(rogue)**:延迟优先。冲刺暴击——在被记录之前行动。
暗线:CMYS 每次在重生泉重编译,都会丢失一小段运行日志。它开始在地牢墙上给自己留言。它不确定留言的是不是"上一个自己"。

### STRINOVA · 弦化行动者(外来者)

从另一个世界"弦络"接入档案的行动者,肉体在别处,进来的只是弦化投影——所以死亡对她们只是掉线。
- **米雪儿(Michele)· 萌新搜查官**:追着一份失踪者名单闯进档案。她逐条核销名单,越核越安静——名单末尾是她自己的名字,登记日期在终末之前。被动"猫踪标记"来自她的搭档炮塔 Pawtector:名单上唯一确认"已归档"的,是送她这只机械猫的人。
- **香奈美(Kanami)· 灵魂歌姬**:她的歌声频率能让被归档者**停下来听**——全档案唯一能做到这件事的东西。代价:每唱一次终曲(Finale),她自己就忘掉一小段歌词。她在和馆长比赛,看是她先唱完,还是先忘完。
- **星绘(Celestia)· 星辉圣所主管**:前馆方高层,亲手在归档名单上签过字。叛出后建立余烬圣所,把签过的每个名字刻在档案高塔里。她的护甲机制(更早、更快恢复)在叙事上是:她已经决定替所有人挡在前面,身体只是先一步执行了。

### NTE · 伊波恩异象猎人(闯入者)

循着"深层异象"信号凿穿档案外壁进来的鉴定师组织,对拯救世界没兴趣——档案里的一切,在伊波恩的市场上都有标价。
- **零号灵能者(Esper Zero)· 鉴定师**:给异象定价的人。编号"零",因为按行规,鉴定师本人必须是"未被鉴定物"。她给馆长的初步估价是:无价——不是买不起,是**不该存在**。
- **娜娜莉(Nanally)· 灵相重拳手**:义肢拳套里住着她死去搭档科林斯(Collins)的灵相——伊波恩式的"归档":把死者装进武器里继续出勤。每次重拳,科林斯都会跟一拳(Collins Follow-Up)。她进档案的私心:查清"灵相"和馆长的"归档"到底有什么区别。她害怕答案是"没有区别"。

## 六、广播残片(广播终端,随机一条)

风格:前半句是排定节目单的温柔,后半句露出底下的东西。示例(完整 16 条见 `StoryLore.ts`):
- "欢迎参观深层档案。请勿触摸展品。请勿成为展品。"
- "寻人启事:37 层管理员今日未打卡。更正:37 层今日不存在。"
- "安全提示:如遇格式化作业,请保持微笑,直到保持不住为止。"
- "今日馆藏总数:一切。今日读者人数:……重播上一条。"
- "叮咚——叮咚鸡提醒您:档案永远记得你。哪怕你已经不记得自己。"

## 七、Old Memory 对话系统(Gemini + 回退)

`server.ts` 的生成提示词已按本世界观重写:NPC 是档案里"未归档完全的回声",说话温柔、答非所问、偶尔精确得吓人。无 API Key 时的回退台词(`LegacyDialogState`)改为从 `OLD_MEMORY_FALLBACK` 池中取三句,双语,保持"劣化录音"的质感。

## 八、写作规范

1. **不解释**。广播不解释归档是什么,Boss 不解释自己是谁。玩家用两条信息拼出第三条。
2. **馆方语言永远温柔**。越温柔越冷:"归档""抽检""回笼""失败品"。
3. **数字要具体**。"11424 天"比"很久"冷得多。
4. **吉祥物不搞笑**。它们认真履行欢乐职责,这才是恐怖的来源。
5. 中文为主文案,英文为等效翻译(非直译,保持同等温度)。
6. 单行长度:图鉴/底部通知中文 ≤ 26 字,英文 ≤ 46 字符(320px 画布限制)。
